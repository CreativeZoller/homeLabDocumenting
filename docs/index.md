# Üdvözlöm a Home Lab dokumentációban

Ez a lab saját, 2.6-os terv szerinti dokumentációja: 10" rack, Firewalla Gold Plus, UniFi Lite 16 PoE, UniFi U7 Pro, Mini-ITX home server (i5-12400, 64 GB, 2× 12 TB ZFS).

A forrás a v2.0 fejlesztési terv a v2.6 módosításokkal. A menüből a tervezés, a hálózat, az eszközök és a munkaállomás oldalai érhetők el.
