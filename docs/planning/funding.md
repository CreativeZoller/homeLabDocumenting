# Pályázatok

A 2.0-es terv szerint egyéni vállalkozóként a bútor és IT eszközök, illetve későbbi szerverbővítés támogatható. Ez nem pályázati anyag, csak a lab dokumentációjába emelt emlékeztető.

## SFG Start!Klar

- Cél: üzleti terv ellenében bútor és IT eszközök beszerzése (asztal, rack, hálózat, szerver komponensek).
- Keret a 2.0 szerint: akár 37 000 € támogatás.
- A [BOM](phases-bom.md) fázisai (1–4 + rack) ide tartoznak.

## Wachstums!Schritt

- Cél: későbbi bővülés, pl. szerverátalakítás.
- A 2.0 szerint a szükséges befektetés 30%-áig.
- Illeszkedik a 2.6 jövőjéhez: 3 node Proxmox cluster, DAS/JBOD, asztali PC frissítés — [Jövőbeli bővítés](future.md).

A pontos kiírás, határidő és elszámolható tételek az aktuális SFG felhíváson ellenőrzendők. A docs nem helyettesíti a pályázati útmutatót.
